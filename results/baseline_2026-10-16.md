## Baseline eval (16 Oct 2026)

A no-graph checker looks up **only DOIs and doi.org URLs written in the draft** on Crossref `updated-by`. It does not fetch consumer pages and does not walk `RESTS_ON`. Retraction / withdrawal / removal → block. Expression of Concern → warn (not a retraction). Corrections, errata, and `new_version` are not flags. Unresolved DOIs and drafts with no DOI **pass**. This is not a medical accuracy score and not a random sample.

Reproduce (offline; recorded Crossref + recorded MoolTrace labelled run):

```bash
.venv/bin/python -m mooltrace baseline --out results/baseline_2026-10-16.json
```

### Labelling rule (written 16 Oct 2026, before the 16 Oct rows were run)

R1 retraction of Lancet HCQ DOI `10.1016/S0140-6736(20)31180-6` → block. R2 known EoC (Khan 2003) or known 2-hop to it (Healthline cinnamon, Everyday Health cinnamon, Allen / Deyno / CTIM / Moridpour / Cochrane) → warn. R3 public-page HTML that contains those same identifiers → warn. R4 public-page HTML with no DOI / PMID / PMCID → pass. R5 public-page HTML with other scholarly ids that are not known flags → pass pending a publisher notice; relabel if a counted path appears. R6 no verifiable source → warn. R7 depth 1 on a review that only reaches Khan at hop 2 → pass.
